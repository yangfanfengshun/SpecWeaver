# SpecWeaver v0.4.5

## 本次更新

- 补充面向用户的完整安装、配置、使用、安全边界与故障排查说明。
- 新增面向 Codex、Claude Code 和 Cursor Agent 的原生插件上下文，明确安装、Skill、MCP、认证信息与外部写操作边界。

- 从本版本开始提供与版本 tag 对应的 GitHub Release 和公开版本说明。
