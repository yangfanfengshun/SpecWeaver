# SpecWeaver v0.5.0

## 本次更新

- 新增一条命令完成用户级安装，自动检测并复用已有的 Codex 和 Claude Code 插件。
- 新增统一的 `specweaver update` 和 `specweaver status`。
- 多个 AI 宿主共用一份认证配置，升级和重复安装不会要求重新填写已有配置。
- 保留 Codex、Claude Code 和 Cursor 原有的分平台安装方式，便于单平台使用和故障恢复。
- Cursor 继续使用原生插件确认与更新流程，统一命令会输出下一步操作。

## 验证结果

- 43 个自动化测试通过，覆盖统一安装、重复执行、已有安装复用、升级配置保护和
  非敏感状态输出。
- Codex、Claude Code 和 Cursor 的插件清单与 MCP 入口一致性检查通过。
