# SpecWeaver v0.7.3

v0.7.3 统一了 0.7 系列的插件说明，并新增轻量的跨项目日报能力。

## 本次更新

- 新增 `daily-report` Skill：任务结束时按项目记录已完成事项，下班时汇总当天所有
  项目；记录按日期和项目合并，并自动去除完全相同的事项。
- 日报按天保存在 `~/.specweaver/daily-logs/YYYY-MM-DD.md`，只记录项目名称和完成
  事项，不自动补写进行中、问题或计划。
- 同步更新 README、通用 Agent、Claude Code、Cursor 规则和三平台插件描述，使安装、
  配置、需求收集、蓝湖设计还原与日报能力保持一致。
- Cursor 更新引导改为重新执行 `/add-plugin`，并明确 `agent` 是有效的 Cursor CLI；
  `specweaver status` 现在区分 CLI 检测结果和需要人工确认的插件版本。

## 验证结果

- 通过日报追加、同项目合并、重复事项去重、多项目汇总和文件权限测试。
- 通过 Skill 结构、插件清单、安装生命周期、版本一致性和发布清单检查。
